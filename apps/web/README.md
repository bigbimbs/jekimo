# Web dashboard

The React and TypeScript dashboard will let authenticated users manage projects and investigate their errors, crashes, and logs through a browser.

It will be built with Vite, React, TypeScript, Tailwind CSS, shadcn/ui, and TanStack Query, and served by the instance as static files with every asset bundled (no CDN). It ships in English only, but every user-visible string comes from an ICU message catalogue under `src/locales/` so other languages can be added later. See "Dashboard" and "Translation" in [docs/architecture.md](../../docs/architecture.md).

Implementation has not started yet.
