# Web dashboard

The React and TypeScript dashboard will let authenticated users manage projects and investigate their errors, crashes, and logs through a browser.

It will be built with Vite, React, TypeScript, Tailwind CSS, shadcn/ui, and TanStack Query, and served by the instance as static files with every asset bundled (no CDN). See "Dashboard" in [docs/architecture.md](../../docs/architecture.md).

Implementation has not started yet.
