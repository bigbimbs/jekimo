# Configuration

Document all runtime settings here as they are implemented. Never include real credentials in examples; use `.env.example` for safe placeholders and keep local `.env` files out of version control.

## Planned settings

These are specified but not implemented yet. Each spec lists its own variables:

- Retention, quotas, and disk thresholds: [retention.md](retention.md)
- Sessions, invitations, project creation, SMTP: [access-model.md](access-model.md)
- Ingestion rate limits: [ingestion-protocol.md](ingestion-protocol.md)

All variables are prefixed `JEKIMO_`.
